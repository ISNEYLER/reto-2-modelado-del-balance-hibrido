# Simulación y Análisis de Micro-Red Híbrida (Solar-Eólica)

Este repositorio contiene un script de simulación desarrollado para analizar el comportamiento dinámico y el balance energético de una micro-red híbrida aislada compuesta por sistemas fotovoltaicos, aerogeneradores y demandas comunitarias a lo largo de un ciclo operativo de 24 horas.
